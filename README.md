# Nextel App

Aplicación Android Push-to-Talk (PTT), inspirada en el flujo de uso de radios: mantener presionado para transmitir y soltar para dejar de hablar.

## Primera etapa
- Interfaz inicial oscura con acentos azul eléctrico y rojo.
- Pantalla principal con canal activo y botón PTT.
- Navegación preparada para Inicio, Grupos, Canales y Perfil.
- Arquitectura Android nativa con Kotlin y Jetpack Compose.

## Estado
Este repositorio contiene el esqueleto inicial de interfaz. **Todavía no transmite audio**. La siguiente etapa implementará señalización y audio WebRTC, primero entre dos teléfonos; luego se incorporarán grupos y canales.

## Identidad visual
El logo/ícono aprobado por el propietario debe conservarse exactamente como fue generado. No redibujarlo ni modificar colores, formas o texto. El archivo PNG original debe incorporarse como recurso de marca sin alteraciones antes de generar el APK final.

## Requisitos
- Android Studio reciente
- JDK 17
- Android SDK 35
